# Start here: my work on THRSimSimple

`README.md` is the original course README. This page is the map of **my** work (driver, experiments, notes).

## Folders

| Folder | What is inside |
|---|---|
| `my_driver/` | My C++ ROS 2 driver (the code that gets scored) |
| `_SCRIPT/` | My scripts, one folder per day: sweeps, live demo, plots, log builder |
| `_RESULTS/` | Every experiment result, one folder per day, grouped by phase, each run in its own `date_time_id` folder |
| `_LOG/` | Personal log (step by step), timeline of all runs, diagrams, one folder per day |
| `_paper/` | Reading list (README in git; the PDFs are downloaded locally only) |
| `_DOCS/` | `ARCHITECTURE.md` (how the code works) and `FLOW.md` (how data flows) |
| `eval_results/` | Raw output of `evaluate.bash` (git-ignored, generated; `_RESULTS/` is the tidy copy) |
| `build/ install/ log/` | Generated by colcon, ignore |
| `simulator/ demo_driver/` | Course files, do not edit |

Day folders are named `YYYY-MM-DD_<kind>` (for example `2026-11-19_script`), so they sort in time order.
Experiments are named `YYYY-MM-DD_HHMM_<id>_<what-it-tested>` (Taiwan time).

## Rules I follow

- Every experiment is logged with date and time in its name, and added to that day's `personal_log.md` and `timeline.md`.
- New day = new `_SCRIPT/`, `_RESULTS/`, `_LOG/` day folders.
